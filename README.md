# 🦠 COVID-19 Data Analysis
### 📊 Exploring Global Cases, Recoveries, Deaths & Government Interventions

---

## 🌟 Project Overview

The **COVID-19 Data Analysis** project is a Python-based application designed to analyze COVID-19 data from different countries and regions.

It uses statistical calculations and data visualization techniques to explore daily cases, cumulative cases, recoveries, deaths, and the relationship between government intervention scores and new cases.

The application provides an interactive menu that allows users to perform statistical analysis and generate visualizations easily.

## 🎯 Project Objectives

- Analyze COVID-19 data using Python.
- Calculate important statistical measures.
- Understand global COVID-19 trends over time.
- Compare COVID-19 statistics across countries.
- Explore the relationship between government interventions and new cases.
- Represent data using charts and graphs.
- Apply Object-Oriented Programming concepts in a practical project.

## ✨ Key Features

### 📈 1. Statistical Summary
- Display dataset information and column details.
- Calculate mean and median daily cases.
- Calculate standard deviation.
- Find maximum and minimum daily cases.

### 🌍 2. Global COVID-19 Trends
- Visualize cumulative cases over time.
- Compare cumulative recoveries and deaths.
- Understand changes in global COVID-19 statistics.

### 🏆 3. Top Country Comparison
- Identify countries with the highest cumulative cases.
- Compare cases, recoveries, and deaths.
- Display comparisons using a grouped bar chart.
- Allow users to select the number of top countries.

### 🏛️ 4. Government Intervention Impact
- Explore the relationship between intervention scores and new cases.
- Apply logarithmic transformation to new case counts.
- Display data using a scatter plot.
- Add a trend line to show the overall linear relationship.

### 📅 5. Country-Wise Case Trends
- Identify the top five countries by cumulative cases.
- Track cumulative cases over time.
- Compare countries using a multi-line chart.

### ⚡ 6. Run All Analyses
- Execute the statistical summary.
- Generate all available visualizations sequentially.

## 📂 Dataset Information

**Dataset Name:** `COVID19_Data_Analysis_Dataset.csv`

The project requires a CSV dataset containing COVID-19 statistics and related information.

### Important Dataset Columns

- `Date` — Date of the recorded data.
- `Country` — Name of the country.
- `Region` — Geographical region.
- `New_Cases` — Number of newly reported cases.
- `Cumulative_Cases` — Total cumulative cases.
- `Cumulative_Recovered` — Total cumulative recoveries.
- `Cumulative_Deaths` — Total cumulative deaths.
- `Government_Intervention_Score` — Score representing government intervention.

The dataset must contain the required columns for the selected analysis functions.
